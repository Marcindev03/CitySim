# CitySim

Projekt symulujący ruch samochodów. Powstał jako 30-dniowy challenge nauki C# po 5 minut dziennie

# Uruchomienie

dotnet run

# Wymagania

.NET 10 SDK

# Ograniczenia

1. Ruch tylko w osiach X oraz Y
2. Kolejność w foreach decyduje kto pierwszy zajmie okupowaną pozycję
3. Start wymaga wolnych pól (`numberOfVehicles <= mapWidth * mapHeight`)
